Drop your portfolio images or clips in this folder.

Any filename and any of these extensions works:
  .jpg  .jpeg  .png  .webp  .avif  .gif  .mp4  .webm

They appear on the site automatically, sorted by filename.
The filename becomes the caption shown on hover, so name them
like "bulletbeats-launch.jpg" -> "Bulletbeats launch".

Tiles are 9:16 (vertical, reel-shaped), so vertical images look best.
